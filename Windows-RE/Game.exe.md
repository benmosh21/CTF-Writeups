# פתרון אתגר הנדסה לאחור: תיקון PE Header וטבלת ייבוא

## מבוא
האתגר התחיל עם קובץ הרצה בשם `game.exe` שמערכת ההפעלה Windows סירבה להריץ, והציגה את השגיאה: `This app can't run on your PC`. מטרת האתגר הייתה לתקן את הקובץ כדי לאפשר את הפעלת האפליקציה.

## שלב 1: זיהוי הבעיה הראשונית וניתוח סטטי
כדי להבין מדוע הקובץ מסרב לרוץ, התחלנו מאיסוף מידע בסיסי וניתוח סטטי של הקובץ:

* **בדיקת סוג הקובץ:** הרצת הפקודה `file .\game.exe` בטרמינל הראתה שהקובץ מזוהה בתור ספריה דינמית: `PE32 executable (DLL) (GUI) Intel 80386`.
* **ניתוח בתוכנת IDA Pro:** טעינת הקובץ ב-IDA אימתה שנקודת הכניסה מוגדרת כ-`DllEntryPoint`. עם זאת, מבט בקוד הראה שמדובר באפליקציית חלונות רגילה לחלוטין. מצאנו קריאה לפונקציית האתחול `_set_app_type(_crt_gui_app)`, ולאחריה לולאת הודעות סטנדרטית של חלונות שכוללת שימוש בפונקציות המוכרות `RegisterClassW`, `CreateWindowExW` ו-`GetMessageW`.

**מסקנה:** ה-PE Header של הקובץ שונה בכוונת תחילה כדי שמערכת ההפעלה תחשוב שמדובר ב-DLL ותסרב להריץ אותו כתהליך עצמאי.

## שלב 2: תיקון ה-PE Header (Patching)
כדי לגרום למערכת ההפעלה להתייחס לקובץ כקובץ הרצה תקין, נדרשנו לערוך את דגלי המאפיינים (Characteristics) של הקובץ.

1. פתחנו את הקובץ בעזרת הכלי `CFF Explorer`.
2. ניווטנו למבנה ה-Headers של הקובץ: `Nt Headers -> File Header`.
3. פתחנו את חלונית ה-`Characteristics`.
4. מצאנו שהדגל `File is a DLL` (ערך `0x2000`) היה מסומן. ביטלנו את הסימון שלו, תוך וידוא שהדגל `File is executable` נשאר מסומן.
5. שמרנו את הקובץ החדש תחת השם `game1.exe`.

בדיקה חוזרת עם הפקודה `file` אישרה שהקובץ מזוהה כעת כ-`PE32 executable (GUI)` נקי.
